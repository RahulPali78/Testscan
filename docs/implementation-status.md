# Implementation status

Updated 26 October 2026.

## Authenticated reference execution

- Verified OIDC/Cognito access JWTs, canonical database memberships and owner/editor/viewer roles.
- Explicit local-only synthetic sign-in; random secrets generated by the development launcher.
- Encrypted HttpOnly browser sessions, same-origin mutation protection and OIDC code/PKCE/nonce/state flow.
- Organisation/project persistence and composite scoped foreign keys.
- Immutable published scenario versions, frozen run manifests and append-only assertions/evidence/audit events.
- Revocable, expiring project service tokens, stored as SHA-256 hashes; service tokens cannot publish criteria.
- Atomic run admission, scoped idempotency conflicts and five active runs per project.
- Transactional outbox, stable Temporal workflow IDs and one business-action attempt.
- Reference adapter with build checks, bounded HTTP requests, execution deadlines and full observation windows before PASS.
- Independent count, tenant/requester and required-field checks; witnessed failures survive interrupted execution.
- Attempt fencing, queued/running cancellation, separate cleanup retry and admission blocked by failed cleanup.
- Dashboard publication, version selection, fault modes, status, assertions, evidence timeline and JSON export.

## Scope and outstanding gates

This is an implementation increment toward the complete product. Only the synthetic
reference agent/state workflow executes. Mandatory unsupported operations are
rejected at publication; broad contract validation does not imply executability.
No customer web/API/agent/mobile/desktop/voice support cell is qualified.

OIDC/Cognito code and signed-token checks exist; a live provider still needs issuer,
client, API audience/scopes and redirect registration before deployment testing.
Production secret management, non-owner database service roles/RLS, membership
administration, independent security assessment and session/provider revocation
procedures remain. There is no refresh-token storage or provider-wide logout.

Evidence currently lives in PostgreSQL, with API authorization and immutability
triggers. Protected object storage, retention/deletion, redaction and production
artifact access are not implemented. The reference app and Temporal development
server are loopback services for synthetic data. Do not expose them to customers.

Customer connections/secret resolution, private runners, adapter conformance,
production egress/isolation, usage reservations/accounting, all remaining adapters,
AWS deployment, release gates and complete-product qualification remain required.
